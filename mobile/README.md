# Aplicativo Mobile em React Native — CardioIA Fase 4

Aplicativo móvel desenvolvido em React Native / Expo para permitir a captura ou upload de exames radiológicos e visualização instantânea de diagnósticos de cardiomegalia.

## 📱 Recursos
- Seleção de exame via Câmera fotográfica ou Galeria de arquivos.
- Card animado de diagnóstico clínico com barra de confiança na paleta oficial FIAP (`#ED145B`).
- Modo de demonstração offline (Mock Mode) para testes sem dependência de servidor ativo.
- Roteiro estruturado para gravação do vídeo de até 3 minutos (`ROTEIRO_VIDEO_MOBILE.md`).

Consulte o guia [`knowledge_base/07_IR_ALEM_2_APP_MOBILE_REACT_NATIVE.md`](../knowledge_base/07_IR_ALEM_2_APP_MOBILE_REACT_NATIVE.md).
