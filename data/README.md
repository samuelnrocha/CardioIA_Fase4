# Diretório de Dados — CardioIA Fase 4

Este diretório gerencia o pipeline de dados da Fase 4.

- `raw/`: Imagens brutas baixadas ou amostras do dataset NIH Chest X-ray.
- `processed/`: Metadados curados (`dataset_curado.csv`), splits de treino/val/teste e imagens normalizadas em $224 \times 224$.

Consulte o guia [`knowledge_base/03_PARTE1_DATASET_E_PREPROCESSAMENTO.md`](../knowledge_base/03_PARTE1_DATASET_E_PREPROCESSAMENTO.md) para detalhes.
